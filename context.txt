[9:28 am, 06/02/2026] Dheram Sreeharsha: Session-spend model (short logic note)

User deposits MON from main wallet → stored in balances[mainWallet] inside contract.

User creates session wallet and calls setSession(sessionAddr, expiry) once.

Contract maps: sessionOf[mainWallet] = sessionAddr.


Gameplay

Session wallet calls: attack(castleId, mainWallet)

Contract checks:

msg.sender == sessionOf[mainWallet]

balances[mainWallet] >= cost

session not expired


Deduct cost from balances[mainWallet], update castle state.

Rewards always sent to mainWallet.


If session lost

Funds safe in contract.

User sets a new session wallet → continues.


Optional

withdraw() lets main wallet reclaim unused balance.
